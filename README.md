# 🎯 Quiz Master (Still being updated)

Quiz Master is an interactive **Quiz Application** built as part of my **BCA 4th Semester Project**.  
It allows users to test their knowledge across different topics with a simple, responsive, and engaging interface.

---

## 🚀 Features
- 📝 Multiple-choice quiz questions
- 🎯 Score tracking and instant results
- 📱 Responsive design (works on mobile & desktop)
- 🔄 Restart and replay functionality
- ⚡ Easy to extend with new quiz categories

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS (Bootstrap, custom styles), JavaScript
- **Backend:** PHP & MySQL (for quiz data and user management)
- **Version Control:** Git & GitHub
